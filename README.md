# SongKey

歌ってみた・カバー動画の URL を貼ると、その動画が**原曲キーから何半音ずれているか**を判定する Web アプリです。

## 使い方

```bash
pip install -r requirements.txt   # ffmpeg も必要です（例: apt install ffmpeg / brew install ffmpeg）
uvicorn songkey.app:app --port 8000
```

ブラウザで http://localhost:8000 を開き、次のどちらかで判定します。

- **原曲の動画URLで比較**（おすすめ）: 判定したい動画と原曲（公式MVなど）の URL を入力します。
- **原曲キーを入力**: 原曲キー（例: `C`, `F#m`, `B♭`）がわかっている場合は URL の代わりに入力できます。

結果は `+2`（原曲より半音2つ上）、`-3`（半音3つ下）、`±0`（原曲キー）のように表示されます。
オクターブ違い（男性が女性曲を1オクターブ下で歌うなど）は `±0` になります。

## 仕組み

1. [yt-dlp](https://github.com/yt-dlp/yt-dlp) で動画の音声を取得し、ffmpeg でモノラル WAV に変換（先頭約4分）
2. [librosa](https://librosa.org/) で打楽器成分を除き、チューニングを推定した上でクロマ（12音の強さ）の平均を計算
3. 原曲のクロマを -6〜+5 半音ずらしたものとカバーのクロマの相関を取り、最も一致するずれをキー差とする
4. チューニング（A440 からのずれ）の差も加えて、再生速度変更などによる半端なずれも表示
5. 原曲キーを手入力した場合は、Krumhansl-Kessler プロファイルで動画のキーを推定して比較

## 制限

- 曲の途中で転調する曲や、アレンジが大きく異なるカバーでは誤判定することがあります。
- ±6 半音は上下の区別がつきません。
- 20 分を超える動画は対象外です。

## 設定

| 環境変数 | 既定値 | 説明 |
| --- | --- | --- |
| `SONGKEY_ANALYZE_SECONDS` | `240` | 各動画の先頭から解析する秒数 |

## テスト
